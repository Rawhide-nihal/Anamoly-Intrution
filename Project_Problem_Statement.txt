Traditional signature-based Intrusion Detection Systems (IDS) mainly rely on known attack signatures, which can make it difficult to identify new or previously unseen attack patterns. Anomaly-based intrusion detection can instead identify network behavior that deviates from expected patterns. Our project aims to develop an anomaly-based intrusion detection approach using the CICIDS2017 dataset, by analyzing network-flow features and investigating DBSCAN and Isolation Forest as two different unsupervised anomaly-detection techniques.
